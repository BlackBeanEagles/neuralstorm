# Small real-world sorting pilot

This kit is ready to run, but **no participant results have been collected**. Do not report a pilot outcome until the CSV has real observations.

1. The included ten-item set uses the four **India 2026 source-segregation streams** (`dry`, `wet`, `sanitary`, `special_care`) as its answer key, based on the [Gazette of India rules](https://egazette.gov.in/WriteReadData/2026/269620.pdf). Use safe clean items and the labelled photo cards for battery and sanitary examples. This measures choosing a stream, not finding a particular site's bin. If you want to test physical bins instead, replace the answer key with the actual site's verified sign or operator instructions. Do not handle used batteries or sanitary waste as demonstration props.
2. Run `python scripts/prepare_pilot.py --participants 6`. It creates anonymous IDs P01–P06 and assigns each item to the app and no-app conditions equally across participants. Six people are useful, but two or four also work for a small pilot. Each person gets half the items with BinWise and half without it, in a shuffled order.
3. Show one item at a time. In the `no_app` condition, give the participant a brief card listing the four stream names. In the `app` condition, they can scan the item using the India profile and use BinWise's advice or its manual confirmation path. Time from showing the item until their final choice. Ask them to state one of the four stream names (or `ask_staff`); record the action label, seconds, and whether BinWise declined an automatic answer. Do not tell them the ground truth until their session is over.
4. Enter observations in `sessions.csv` and run `python scripts/analyze_pilot.py`. The script writes `results.json` with descriptive accuracy and time for each condition, paired changes for people who completed both conditions, and the number of app declines.

Use anonymous IDs only. Do not record faces or names in `sessions.csv`. This is a convenience pilot, not proof of population-level impact. Report sample size, item list, setting, how ground truth was checked, and the study limitations with any result. The current model does not classify all four streams; its ability to decline an unsupported item is part of what this pilot tests.
